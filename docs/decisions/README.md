# Decision records

This repo's canonical decision log predates this directory and remains
authoritative: the D1–D14 table in [`../00-overview.md`](../00-overview.md)
(each with a rationale anchor) and the numbered engineering contract in
[`../../CONVENTIONS.md`](../../CONVENTIONS.md).

The files here are one-page anchors in the standard decision-record format so
tooling and agents that look for `docs/decisions/` find them. Each cites its
D-number / CONVENTIONS section. If a record here ever disagrees with
`00-overview.md` or `CONVENTIONS.md`, those win — fix the record.

New decisions: add the rationale to `00-overview.md` or `CONVENTIONS.md` first
(per the "change it in the same commit, with evidence" rule), then mirror a
short record here.
