Add the app icon (1 minute)

This puts RecipeCollater on your home screen so it opens full-screen, like a normal app, with no address bar.

  1. Open {{ app_base_url }} in Safari on your iPhone (it has to be Safari — Chrome can’t add to the home screen).
  2. Tap the Share button at the bottom — the square with an arrow pointing up.
  3. Scroll down and tap Add to Home Screen, then Add.

On Android, open the same address in Chrome, tap the … menu, and choose Add to Home screen.

On a PC there’s nothing to install: Add a recipe takes a pasted or dropped link, and has a one-click bookmark for your bookmarks bar.

2. Build the Shortcut

  1. Open the Shortcuts app and tap + to create a new shortcut.
  2. In the shortcut's settings, turn on Show in Share Sheet and accept URLs.
  3. Add a Get Contents of URL action and point it at: 
    {{ ingest_url }}
  4. Set Method to POST.
  5. Under Headers, add Authorization with the value: 
    Bearer {{ new_token if new_token else 'YOUR_TOKEN' }}
    {% if not new_token %}(Create a token above to see the full value here.){% endif %}
  6. Set Request Body to JSON with one field url, whose value is the Shortcut Input (the shared link).
  7. Save it as “Send to RecipeCollater”. Now share any recipe page, YouTube video, or Instagram reel and pick it.

3. Instagram, and sites that block automated fetching (optional)

Public Instagram reels work from the Instagram app's share sheet — the recipe is read from the post's caption. Private or followers-only posts can't be read that way, and a few recipe sites reject server requests outright. For those, capture the page's HTML in Safari and send it along, so the recipe is read from what your phone already loaded while signed in.

  1. In the Shortcut, add Run JavaScript on Web Page before the request and return document.documentElement.outerHTML.
  2. In the JSON body, add a second field html set to that JavaScript result (keep url too).
  3. For a private Instagram reel: open it in Safari (not the Instagram app) while signed in, then share from there so the JavaScript step can capture the caption.

The server still de-duplicates by URL, so sending HTML never creates a second copy.

4. Share it with the household

Once your Shortcut works, hand it to your partner so they can add recipes too — no rebuilding.

  1. In the Shortcuts app, press and hold your “Send to RecipeCollater” shortcut and choose Share → Copy iCloud Link.
  2. Send that link (Messages, etc.). They open it and tap Add Shortcut — the address and token are already inside, so it just works on your home Wi-Fi.
  3. Prefer separate tokens? Have them open this page on their own device, create their own token in step 1, and paste it into the shortcut's Authorization header. You can revoke any token later on the Devices page.

Sharing while away from home won't reach the PC — save the link and send it once you're back on your network (or set up remote access later).
